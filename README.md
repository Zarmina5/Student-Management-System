# Student Management System (Python)

##  About the Project

This is a console-based Student Management System developed in Python to practice core programming concepts. The project allows users to manage student records through a menu-driven interface and stores data permanently using JSON files.

This project was built independently as part of my Python learning journey.

---

##  Features

==> Add a new student
==> Display all students
==> Search students by:

  ==> Roll Number
  ==> Name
==>Update student information
==> Delete student records
==> Sort student records
==> View student statistics
==> Save data using JSON
==> Load data automatically when the program starts
